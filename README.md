Neon Salvage is a 2D canvas arena shooter: you pilot a salvage skiff through a neon asteroid field, blasting chaser, shooter and splitter drones, collecting the energy cores they drop, and surviving 10 escalating waves — including a boss drone every 5th wave — to clear the sector. Chained kills raise a combo multiplier that a single hit resets; dash, shield, rapid-fire and rare extra-life pickups keep the run alive, and clearing wave 10 opens endless mode. Everything is drawn in code and every sound is synthesized with WebAudio — no image or audio files, no libraries, no network.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
